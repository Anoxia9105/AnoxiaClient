功能一览

Features
💬实时消息

支持文字、图片、语音、视频、文件、表情与位置；长按或右键消息可撤回、转发、收藏与引用。

📹音视频通话

在单聊或群聊中一键发起通话，支持多人会议、共享屏幕、举手表情与通话录制提示。

✨AI 助手

选中消息文字即可让 AI 解释、翻译、总结、润色、扩写；支持自定义指令与智能回复建议。

📝记事本

带文件夹层级的全功能笔记：富文本、代码块、图片、标签、回收站与版本历史，可分享回聊天。

⭐收藏

右键 / 长按消息即可收藏，支持按类型筛选与全文搜索，跨会话沉淀重要信息。

😊表情包

上传自定义图片表情包，手机 / 桌面 / Web 多端同步，聊天输入框直接选用。

🔍全局搜索

顶栏搜索框一步直达：会话、联系人、历史消息上下文，结果可直接跳转定位。

📱多端同步

同一账号多设备登录，消息增量同步、设置与表情包共享，离线队列自动补发。

常见问题

FAQ
?如何隐藏官方帮助入口？

在「设置 → 通用」中关闭“显示官方帮助入口”，会话列表将不再显示本房间，随时可再打开。

?AI 助手怎么用？

在输入框选中文字或右键 / 长按消息，选择“问 AI / 解释 / 总结 / 翻译 / 润色 / 扩写”，也可输入自定义指令；智能回复会在智能回复栏给出 3 条建议。

?通话支持加密吗？

支持。通话界面显示“E2E 加密已启用”标识即表示端到端加密已生效；主持人可对成员静音或移出会议。

?消息发错了怎么办？

右键 / 长按自己发送的消息选择“撤回”，群内可转发给正确的会话；重要内容建议先“收藏”再发送。

?如何自定义主题与强调色？

「设置 → 外观」提供 14 组强调色（经典活力 / 柔和莫兰迪 / 深邃夜色 / 温暖大地）与自定义取色，并支持深浅色主题与背景视频。

i设计说明 & 改动清单

  • 新增「粘性章节导航」chips：长页面内 7 个锚点（概览/快速操作/上手/功能一览/FAQ/贴士/入口），自绘胶囊按钮（主题强调色底 + RadiusToken.pill 圆角，不用 ActionChip 默认样式），点击滚动到对应区块并避开吸顶条遮挡。
  • Hero 区状态化：版本徽章 + 服务连接呼吸点 + “检测到新版”提示，把 appVersionProvider / ws_state 信息上移，用户一眼掌握环境状态。
  • 新增「更新 / 公告」卡：整合 settingsPageController.checkUpdate() 与公告（announcement）入口，主 CTA “立即检查更新”可关闭暂不提醒。
  • 快速操作按平台裁剪：桌面端 / Web PC 六卡（添加好友 / 发起群聊 / 系统公告 / 检查更新 / 分享 / 设置，走 presentAdaptivePage 弹窗）；移动端六卡（增加「扫一扫」，隐藏「系统公告」，走页面跳转）；「扫一扫」为原生移动端专属，Web 与桌面端一律不展示。
  • 功能引导 4 → 8 项手风琴：补齐项目真实能力——AI 助手（chat_ai / note_ai）、记事本（版本历史 / 导出）、收藏、表情包、全局搜索、多端同步；位于「快速上手」之下，与常见问题同为点击展开面板样式。
  • FAQ 4 → 5 条：覆盖 AI 用法、E2E 加密、撤回、主题强调色等高频疑问，手风琴单开。
  • 新增「小贴士」3 条：置顶 / 免打扰 / 多端登录，均对应已有能力（chat_pin / chat_do_not_disturb）。
  • 修复 i18n 缺失：旧版 official_room_action_* / onboarding_* / faq_* / nav_* / footer_* 共 30+ key 在 zh/en/ja 中不存在，页面渲染原始 key；实施时需补齐三语文案（本稿文案即定稿）。
  • 排版与层级：内容最大宽 780px 居中；卡片 15px 圆角、hover 上浮 2px + 阴影；强调色默认 Indigo #5E66D0，跟随主题 14 色 + 自定义取色。
  • 移动端策略：功能一览与 FAQ 同为折叠面板、步骤 2×2、Hero 压缩；与现有 compact（<520/<620）降级逻辑一致。
  • 无障碍：保留现有 Semantics label；卡片区全部可焦点化；呼吸点动效需响应“减少动效”设置（settings_reduce_motion）。
  • 不动的部分：官方房间仍为纯前端虚拟房间（official_welcome），不渲染消息流与输入框；ChatAppBar 保持现有结构，仅确认副标题显示 official_room_list_hint。
  • 实施文件：重构 official_room_home_view.dart 与 official_room_sections.dart（拆分为 quick / features / steps / faq / tips / nav 六个 section widget），i18n 三语补齐，图标沿用 hugeicons 线性风格。
