# 聊天与联系人加载状态

- 首次加载无缓存时显示骨架屏；网络失败、异常响应或超时显示重试按钮，不能作为空列表处理。
- 主动刷新保留已有列表；失败后在列表上方显示重试入口。首次同步成功前，数据库空通知不能覆盖加载或错误状态。
- 联系人分组透传上游首次加载和错误状态；后台刷新不替换已有分组。
- 房间消息订阅在离开后保留五分钟，切回可同步读取缓存（包括已加载的空房间）。到期释放订阅；Token 变化重建订阅，退出登录返回空消息。
- 房间进入同步继续执行；骨架屏只用于尚未取得消息数据的首次进入。

回归测试：`contact_list_retry_test.dart`、`room_messages_cache_test.dart`、`sync_repository_consistency_test.dart`。手动验收可断网首次进入列表，再联网点击重试；加载房间后 A → B → A，确认消息、标题与输入框不闪骨架屏。
