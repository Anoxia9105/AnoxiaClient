# 移除聊天气泡回执

- 不再显示单条消息的已读、已送达或未读状态；成功发送后，气泡侧边不占位。
- 保留发送中、发送失败重试和 @ 提及提示。发送成功仅表示服务端 ACK，不代表对端收到或阅读。
- 删除对端回执判定工具、成员模型的 `lastReadSeq` 以及对应翻译和旧测试。
- 服务端成员资料接口不再返回其他成员的 `lastReadSeq`，客户端不再读取该字段。
- 保留会话自身的阅读水位、`read_cursor` 和数据库 `read_seq`，它们用于会话列表未读角标、标记已读和多端同步，不是对端气泡回执。
- 无数据库或 protobuf 变更。客户端和服务端均需升级；旧客户端仍可能自行显示旧版降级标签。
