# 通话与手机视频体验修复（2026-10-10）

## 行为

- 创建群聊时可选图片、裁剪正方形头像、上传和移除；上传期间禁止提交。创建接口新增可选 `avatarUrl`，旧客户端仍可不传。
- 手机群语音也展示成员网格，任意成员开启摄像头后显示视频。双人视频点击小窗交换主画面；拖动累积每次位移，视频纹理独立于位置动画。
- 有桌面共享时显示「横屏查看」入口。全屏查看器按当前视口旋转，并支持双指放大，关闭后返回通话；不依赖浏览器的方向锁定授权。
- 来电提示居中、宽度最多 360，头像缩到 56。Windows 来电系统通知保留 incomingCall 场景和按钮，头像所在列缩到三分之一。
- 连接失败内容宽度最多 360，小屏可滚动。断线按 SDK 原因显示解释，记录原因、房间和远端人数，不记录 token。
- SDK 已耗尽恢复后，仅网络/媒体类断线额外尝试 2 次（2 秒、5 秒）。稳定连接 30 秒后重置预算。终止类原因不恢复，挂断/销毁取消计时器，恢复保留麦克风和摄像头开关。
- 回到前台重新查询群通话状态；开始/结束事件优先于旧 HTTP 响应。正在请求时收到恢复前台事件，会在结束后补查，避免锁屏期间的结束消息被旧结果覆盖。
- 视频详情打开即初始化元数据和进度条，关闭自动播放时保留封面直到播放。运行时错误可重新创建播放器重试。

## 服务端配套

新视频上传统一为 H.264/yuv420p + AAC MP4，长边不超过 1920，索引前置。上传响应新增可选 `sizeBytes/name/mimeType`，发送消息采用规范化元数据；消息服务也校正匹配上传 URL 的视频事实。旧响应和缓存保持兼容。

服务端必须安装含 libx264/AAC 的 FFmpeg，参见服务端 `docs/FFMPEG-DEPLOYMENT.md`。默认转码超时 120 秒。配额按实际 MP4 + 封面结算，失败时删除对象并回滚配额。旧视频对象不会自动迁移。

真实手机与 Windows 两端通话、长时间随机断线、系统通知原生呈现仍需设备联调；测试中的假参与者不建立 LiveKit 或原生 WebRTC 连接。随机断线原始触发原因尚未在真实网络复现，有限恢复不代表已确认根因。


## 2026-10-12 手机通话与输入面板修复

- 私聊全屏来电的接听 / 拒绝与语音接听入口居中；手机拒绝、取消等终端信令复用统一 Toast。
- 手机信号柱底部对齐；移动通话控制栏隐藏媒体设置入口。
- Windows 被叫立即打开连接页，由独立窗口取令牌，避免主窗口缓存旧令牌及取令牌失败时没有重试页面。
- 主动重试先等待旧媒体释放，再清除令牌对应的错误缓存；服务端返回同一 JWT 时也允许本次显式重连。页面已退出时不交付重试结果，普通挂断仍禁止自动重连。请求失败通过统一 Toast 反馈。
- 手机 AI 助手移入更多面板，保留功能开关；自定义生成按钮与重试按钮文字显式白色。
- 手机 @ 选择器改为全宽底部列表，支持搜索、空状态和拖动收起键盘，选择后返回输入框。
- Windows 原生通知采用左头像、右文案、底部横向动作；白色透明 PNG 由 HugeIcons SVG 生成，升级缓存名避免使用旧图标。应用内来电卡片同步布局与白色按钮内容。

原生系统通知的按钮文字前景色由 Windows 渲染，XML 仅提供 Success / Critical 按钮样式，没有独立的文字颜色属性；因此不能保证所有 Windows 版本和主题均呈现白色文字。

本次按要求不运行编译、Flutter 测试和设备联调。验证使用 Dart 格式化、涉及文件静态分析与 git diff --check；补充了重试等待释放 / 退出取消、按钮前景色与通知 PNG 白色像素的回归断言，测试代码未执行。本次消息没有附带报错截图，手机发起视频、Windows 接听的真实媒体连接结果仍需设备复测。


### 截图补充后的修正

截图中的 Windows 接听失败是 HTTP 鉴权的「登录过期」，并非已经确认的 LiveKit 媒体建连错误。上一版重试逻辑只处理媒体与令牌错误缓存，不足以覆盖这个问题。

- 通话子窗口为每次 HTTP 请求通过进程内通道读取主窗口当前登录态；主窗口校验 roomId + session，仅允许当前通话窗口访问。不把凭据放入窗口参数或日志，不从子窗口写回持久化登录态。主窗口清除登录态后不再回退到子窗口旧凭据。
- 凭据加载失败时显式结束 Dio 拦截链并返回错误，避免重试等待不返回。补充最新登录态、旧会话拒绝、登出后拒绝和加载失败完成请求的断言。
- 撤销上一版误改的应用内来电卡片及对应测试；保留仅作用于 Windows 原生系统通知的布局 / 白色 HugeIcons PNG 修改。原生通知文字颜色仍由系统样式控制。
- @ 搜索图标按现有搜索框做法用 SizedBox + Center 限定为 20px；手机通话人员占位头像使用 AvatarWidget 默认方形圆角。
- 手机离线来电英文源于服务端 JPushSender 的硬编码提示，服务端另行改为中文默认文案（当前设备绑定没有语言字段）。需要部署服务端修复才影响离线系统通知。

仍按用户要求只做源码与静态检查，不编译、不运行测试或设备联调。
