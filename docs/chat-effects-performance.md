# 聊天特效绘制优化

## 问题与调整

生日和星星下落原先每帧逐个绘制 emoji 段落，并用整个聊天区域的 `saveLayer` 实现透明度。宽屏 36 个粒子的文字绘制及全屏离屏合成开销较高。

现在每场动画仅一次性生成 emoji 小图集（相同 emoji 共用纹理格，保留规则中的出现权重）。每帧复用变换和颜色数组，通过一次 `drawRawAtlas` 批量绘制，使用逐粒子透明度淡出，不再生成全屏离屏层。图集按设备像素比生成，最高 3 倍；纹理随动画结束或页面关闭释放。

关键词、粒子数量、3.5 秒时长、无弹窗、减少动效、开关及消息去重策略均沿用既有规则。粒子重叠处的透明度与旧整层合成略有差异；窗口跨不同缩放比例的显示器时会重新生成图集和随机轨迹。

## 同环境离屏测量

Windows，Flutter 3.44.0 原生 `flutter_test` 引擎；1080 × 720 视口、36 个生日粒子、动画进度固定在 1.4 秒。预热 10 帧后重复 3 轮，每轮 30 帧，计时包含绘制记录、实际栅格化及像素读回。

| 版本 | 第 1 轮 | 第 2 轮 | 第 3 轮 |
| --- | ---: | ---: | ---: |
| 优化前 | 25.75 ms/帧 | 26.74 ms/帧 | 25.36 ms/帧 |
| 图集批量绘制 | 5.14 ms/帧 | 4.99 ms/帧 | 5.44 ms/帧 |

平均离屏耗时降低约 80%。此数据用于比较相同环境的稳态绘制成本，不代表真机或浏览器 FPS；未计入首次图集生成、完整聊天页合成以及不同 GPU 的差异。

复测命令（先按 AGENTS.md 刷新 Dart 协议）：

```powershell
flutter test test/features/chat/effects/chat_effect_rain_test.dart --no-pub --dart-define=CHAT_EFFECT_BENCHMARK=true
```

默认测试跳过耗时基准，常规回归会检查生日/星星每帧一次批量绘制、无全屏离屏层、无重复段落绘制，以及图集权重、高分屏尺寸、真实像素、淡出与资源释放。
