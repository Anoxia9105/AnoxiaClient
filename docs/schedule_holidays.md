# 月视图农历与节假日

日历设置入口位于日程工具栏。节假日地区、农历开关各自本地保存；首次进入按语言默认选择中文→中国大陆并开启农历、日文→日本、英文→不显示假期。之后切换语言不会改变地区或农历选择。

月视图日期区域显示节日名称和休/班标记；没有假期数据时保持空白，不显示提示文案。普通日期显示农历日、初一显示农历月份（含闰月），传统节日优先。节日名称与农历同处一行时，悬停可查看完整信息。个人日程独立排列，空间不足显示“另有N项”，点击展开当天列表。

内置快照：CN 2025/2026，JP 2025/2026/2027；来源、年度核对及服务端部署说明见相邻服务端的 `docs/SCHEDULE-HOLIDAYS.md`。客户端先显示缓存或内置快照，后台从自有接口 `/schedule/holidays` 获取更新，按地区与年份缓存6小时。未公布、网络失败、错地区和截断数据不会覆盖有效旧版。合并前一年、当年、下一年公告，以处理月网格跨年和中国跨年修订。

农历采用MIT许可的`lunar 1.7.8`本地计算，显示范围1901—2099年，不依赖网络；休班数据绝不使用历法库内置调休表。

验证：

```sh
flutter test test/features/schedule
```

包含完整2026年中国休班集合、日本特殊休日、农历初一/节日/闰月、缓存更新/失败保护，以及320/768/1440px下点击日期→新建→保存→月视图显示的完整页面测试、语言与地区分离、同日多条展开。

本地视觉验收可运行 `flutter run -d web-server -t test/manual/schedule_preview.dart --web-port 7357`，使用真实主题、字体和内置假期；个人日程仅存内存，不访问真实账号。
