AnoxiaClient · 优化现有 announcement_dialog.dart 的提案（现有为纯 AlertDialog，无层级区分 / 无队列指示 / 错误样式弱）
强调色
① 层级视觉区分普通公告：强调色喇叭图标 + 「系统公告」；需确认公告：琥珀色盾牌图标 + 「需确认」徽章，一眼可辨，阻断感来自色彩而非弹窗样式。
② 队列进度指示左下角圆点 + 「n/m」，告知用户还有几条公告，缓解连弹多窗的挫败感（对应 presenter 逐条出队逻辑）。
③ 正文限高滚动正文区 max-height 滚动，弹窗高度稳定，不随长文案顶出屏幕；文字保留可选中（对应 SelectableText）。
④ 错误内联 + 重试确认失败时在按钮上方显示内联错误条（复用 announcement_ack_error），按钮变「重试」（复用 announcement_retry），失败不丢焦点、不自动关窗。
⑤ 移动端 Bottom Sheet小屏（移动）改用底部弹出面板 + 拖拽条，正文触控区更大；桌面保持 480px 居中弹窗（与现 ConstrainedBox(480) 一致）。
⑥ 键盘与焦点普通公告：Esc / 点遮罩可关闭（关闭后静默 markRead）；需确认公告：不可关闭，焦点默认落在「确认知悉」。
